# vsdiff

Guided code review in your editor. Your coding agent writes the route through a
Git diff; you walk the stops, ask questions beside the code, and send structured
feedback back to the agent.

- Native diffs, an outline, and an optional pinned Overview.
- Inline guide text with working reply threads.
- Keyboard navigation, coverage tracking, and a final review decision.
- Local files as the agent interface; no vsdiff account or model subscription.

Install the companion CLI and try the sample review using the
[repository quickstart](https://github.com/albertusdev/vsdiff#install).

Requires VS Code 1.104 or later. Distributed under the
